# PRE-CALL

בונה תסריט שאלות לשיחת אפיון, לפני שכותבים הצעת מחיר.

כלי HTML עצמאי (עמוד אחד, בלי בילד, בלי תלות בשרת) שמכין אתכם לשיחת היכרות עם לקוח פוטנציאלי: מאפיין את העסק שלכם פעם אחת, אוסף מה שידוע על הצד השני, ומייצר תסריט שאלות מובנה + כרטיס קריאה לתשובות ששומעים בשיחה.

## למה זה קיים

הצעת מחיר לא נתקעת בכתיבה. היא נתקעת בזה שיוצאים מהשיחה בלי המספרים שצריך כדי לכתוב אותה. הכלי מייצר את השאלות שמוציאות את המספרים האלה, בסדר שמונע מהשיחה לגלוש לכיוונים כלליים.

## שימוש

1. פתחו את `index.html` בדפדפן (אין צורך בשרת או בהתקנה).
2. **שלב 1 · אפיון העסק שלכם** — העתיקו את הפרומפט המובנה, הריצו אותו ב-Claude או ב-ChatGPT, וענו על השאלות. מפיק פרופיל עסק מובנה.
3. **שלב 2 · הזנת הפרופיל** — הדביקו את הפלט (הכלי מחלץ שדות אוטומטית) או מלאו ידנית: מה אתם מוכרים, למי, יחידה תחומה ומחיר, העסקה האחרונה, ומה הלקוח האחרון הרוויח.
4. **שלב 3 · הצד השני** — הדביקו פרופיל לינקדאין/אתר של הצד השני, או השתמשו בפרומפט המובנה למחקר מעמיק (Deep Research). הוסיפו טריגר ידוע ואיך הגעתם זה לזה, אם רלוונטי.
5. **שלב 4 · התסריט** — מקבלים תסריט מלא: שאלות עומק, סדר מחייב, נקודות עצירה, מהלך לניסוח בעלות על הבעיה, נעילת מספר ותאריך, וכרטיס קריאה שמתרגם תשובות נפוצות לסוג ההצעה המתאימה. אפשר להעתיק כטקסט או להדפיס/לשמור כ-PDF.

שני סוגי נתונים, שתי מדיניות שמירה שונות בכוונה:
- **פרופיל העסק (שלב 2)** נשמר ב-`localStorage` של הדפדפן ונטען אוטומטית בפעם הבאה — הוא נועד להתמלא פעם אחת ולשמש לכל שיחה. אפשר למחוק אותו בכל רגע עם הכפתור "מחק פרופיל שמור מהדפדפן הזה".
- **פרטי הצד השני (שלב 3)** נשארים רק בזיכרון JS של הטאב, ונמחקים בסגירת הדף — בכוונה, כי אלה פרטים על אדם ספציפי לשיחה ספציפית, לא משהו שכדאי שיישאר שמור בדפדפן.

בשני המקרים שום דבר לא נשלח לשרת.

## הרצה

הכלי הוא קובץ `index.html` יחיד (HTML + CSS + JS מוטבעים, ללא תלות חיצונית). אפשר:

- לפתוח אותו ישירות מהדפדפן.
- לארח אותו כ-GitHub Pages (הפעילו ב-Settings → Pages, ענף זה, תיקיית root).

## מבנה

```
index.html   כל הכלי — מבנה, עיצוב ולוגיקה
README.md    הקובץ הזה
```

## מגבלות מכוונות

הכלי לא מייצר מחיר ולא מייצר הצעה. הוא מכין את השאלות והמסגרת לשיחה שממנה יוצא המספר שההצעה תיבנה עליו.
